# T5.33 — Responsável obrigatório em toda tarefa

Pedido do Ander (11/11): "obrigatoriamente as tarefas precisam ter pelo menos um responsável". Vale também para as subtarefas (T5.32).

## Regra
- **Toda tarefa nova precisa de um responsável principal.** Só adicional, aprovador ou observador não basta.
- **Trocar as pessoas** de uma tarefa não pode deixar sem responsável principal.
- A **subtarefa** também precisa do responsável dela (cada uma pode ter pessoa diferente).
- **Tarefas antigas sem responsável** (hoje 4 ativas) não foram mexidas, mas ficam **destacadas em vermelho** ("Sem responsável") e **não deixam editar nem mudar o status** até alguém definir o responsável em "Pessoas → Mudar". Arquivar continua permitido.
- Quem cria uma tarefa pelo formulário já vem como responsável (pode trocar, não pode deixar vazio).

## Onde vale (banco, não só tela)
- Criar/editar tarefa, mudar pessoas, mudar status (inclusive arrastar no Kanban e nas filas), liberar demanda, tarefas do onboarding, MCP (Claude).
- **Reunião → tarefa:** o responsável é o dono do item; se não tiver dono, quem está criando a tarefa.
- **Alerta → tarefa:** continua usando o responsável do alerta ou quem está criando.
- **Tarefa que se repete:** se o responsável da tarefa modelo saiu da Central, quem criou a repetição assume.
- **Onboarding, "Todo o setor":** continua colocando todos do setor como responsáveis; se o setor não tem ninguém na Central, o sistema recusa e pede uma pessoa (antes a tarefa ficava solta no setor).
- **Liberar demanda:** o responsável de cada linha passou a ser obrigatório.
