# T5.23 · Período do histórico e limpeza dos dados de conversa (10/11/2026)

## O que mudou para você (Tracking → Configurações → WhatsApp pelo servidor)
- **Histórico antigo do aparelho:** com "Guardar as conversas" ligado, aparece o seletor *não puxar / 30 / 60 / 90 / 180 dias / 1 ano / tudo*. Vale para o histórico que chegar daqui para frente e **não apaga** o que já foi guardado. Conexões que já existiam ficam em "tudo" (como eram); o padrão de 30 dias vale só para conexões novas.
- **Limpar os dados de conversa deste cliente (só administrador):** dois passos, sem e-mail:
  1. mostra quantas mensagens, pessoas e sugestões serão apagadas e o que fica;
  2. pergunta de novo "Você quer mesmo apagar?" e só então apaga.
  Apaga texto, telefone, nome e sugestões (de **todos os WhatsApps do cliente**). **Mantém** as conversas (só com o código cifrado do telefone), as vendas marcadas e as contagens. Fica registrado no histórico de auditoria quem apagou e quantos itens, sem dado pessoal.

## Onde fica o botão (T5.28, 11/11)
O botão **"Limpar dados deste cliente"** (só administrador, com a confirmação em duas perguntas) agora aparece também **na linha do cliente**, em Tracking → Configurações → "Site e/ou WhatsApp", sempre que o cliente tem um WhatsApp pelo servidor ligado. Continua também dentro da configuração do WhatsApp (item 6). Cliente sem WhatsApp ligado não tem o botão, porque não há conexão para apontar.
