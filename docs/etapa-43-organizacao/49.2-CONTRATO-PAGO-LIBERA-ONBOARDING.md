# 49.2 — Contrato Pago libera para o Onboarding (07/11/2026)

Pedido do Ander: na coluna **Contrato Pago** do Comercial, a liberação agora é **para o Onboarding**, não para a operação.

## O que encontrei
O funcionamento já era esse desde a 38.2/43.7: ao liberar, o cliente entra no menu **Onboarding**, na coluna **Onboarding Pendente** (que agora exige reunião, 47.1/47.2). O que ainda dizia "operação" era só o texto.

## O que mudou (só textos, sem banco)
- Botão do cartão e título do painel: **"Liberar para o onboarding"** (antes "para a operação").
- Dica da coluna Contrato Pago: "Use “Liberar para o onboarding” no cartão".
- Cabeçalho do Comercial: "Quem fecha contrato é liberado para o Onboarding."
- Caixa de seleção: "Liberar para o Onboarding"; mensagem quando o cliente já estava no fluxo: "já estava no Onboarding".
- Não mexi no botão **Liberar demanda** do menu Onboarding (é outra coisa: distribui tarefas aos setores).

## Testes
Unitários e `ops-commercial` (navegador) OK; `check:secrets` OK. Sem mudança de banco, permissões ou regras.
