# Etapa 39.3 — Perfis e origem (classificação, ligação com o Meta/Google e rankings no banco)

> **Status:** pronta (17/10/2026). Fase de "motor": os números já saem do banco; as telas dos rankings são a fase 39.4.
> **Ainda não testada com uma planilha real** (falta a chave do Google). Testada com dados simulados dentro do banco real (desfeitos no fim).

## O que ficou pronto
1. **Perfil de cada linha:** o valor da coluna de perfil passa pelas regras do cliente (as que você marcou na configuração).
   - "Lojista", "Sacoleiro", "Consumidor final" → o perfil;
   - valor sem regra ou vazio → **Não identificado** (nunca é chutado).
2. **Origem de cada linha (campanha, conjunto, anúncio do CRM):**
   1. **pelo ID**, nesta ordem: ID do anúncio → ID do conjunto → ID da campanha;
   2. **sem ID, pelo nome** (maiúsculas e espaços a mais não importam), mas **só quando existe um único item com aquele nome** dentro do cliente — e dentro da campanha/conjunto já encontrados;
   3. dois itens com o mesmo nome → **"nome ambíguo"** (não liga a nenhum);
   4. nada encontrado → **"origem não encontrada"**; sem nenhuma coluna de origem → **"sem origem"**.
   Essas linhas **contam no total**, mas não entram no ranking.
3. **Contato único:** o mesmo telefone/e-mail (pela impressão digital) conta **uma vez**, mesmo que apareça em várias linhas. Sem telefone/e-mail, cada linha conta como um contato.
4. **Rankings prontos no banco**, por período (data do contato na planilha):
   - campanhas, conjuntos ou anúncios, com quantos contatos de cada perfil;
   - abrir uma campanha mostra os conjuntos dela; abrir um conjunto mostra os anúncios;
   - investimento do item no mesmo período (Meta/Google), **separado por moeda**;
   - cards: contatos únicos, lojistas, sacoleiros, consumidores, não identificados, quantos com origem, ligados por ID ou por nome, ambíguos, não encontrados;
   - linhas sem data ficam fora do período e aparecem contadas à parte.
5. **Registros usados nos números**, sem dados pessoais (linha da planilha, data, perfil, campanha/conjunto/anúncio, como foi ligado), com filtros: perfil, campanha, conjunto, anúncio, "nome ambíguo", "não encontrada", "sem origem", "sem data".
6. **Regras de ordem do ranking** (no código compartilhado, com testes): por quantidade do perfil, por % do perfil ou por custo por contato (menor primeiro); **empates ficam na mesma posição**; item sem investimento ou com duas moedas fica sem custo (vai para o fim), nunca com custo estimado.
7. **Mudou uma regra de perfil? Vale na hora**, sem ler a planilha de novo. O CRM recebeu um anúncio novo na sincronização? A ligação também passa a valer na hora.
