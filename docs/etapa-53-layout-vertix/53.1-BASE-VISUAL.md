# Etapa 53.1 — Novo layout (estilo Vertix): base visual (09/11/2026)

## Origem
Layout comprado "Dashboard v14" (Vertix), recebido em .rar. Revisado antes: projeto React/Vite sem chamadas de rede, `eval` ou scripts externos (só a fonte Inter do Google e o tema salvo no navegador). **Nada do código dele entrou no sistema**; só o estilo foi usado como referência.

## Decisões do Ander
- Cor de destaque: **azul** (a nossa), não laranja.
- Menu: **barra lateral mantida** (ordem fixa Visão geral · Operações · Anúncios · Análise · Sistema).

## O que mudou nesta fase (só aparência, nenhuma regra)
- Fundo da página cinza suave (`--color-canvas`), cartões brancos mais arredondados e com sombra quase invisível.
- Botões e botões de ícone em formato de pílula; botão secundário com contorno mais leve.
- Campos e avisos com cantos mais arredondados; janelas (pop-ups) bem arredondadas.
- Cabeçalho das tabelas com cantos arredondados.
Arquivos: `index.css`, `components/ui/{card,button,field,alert,toast,icon-button,modal}.tsx`.
