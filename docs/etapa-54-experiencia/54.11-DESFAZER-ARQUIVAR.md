# 54.11 — "Desfazer" ao arquivar (27/11/2026)

Ao arquivar um **contato**, um **rascunho de campanha** ou uma **regra de monitoramento**, o aviso no canto da tela agora tem o botão **Desfazer** (fica 9 s na tela).
Nada é apagado: desarquivar só limpa a data de arquivamento. O histórico do contato registra "arquivamento desfeito".

## Banco (migration `20261127190000_desfazer_arquivamento`)
- `contact_unarchive`, `builder_draft_unarchive`, `monitor_rule_unarchive` (função fina pública + `private.*_impl` security definer). Mesmas permissões de arquivar; só `authenticated` executa.
- `tracking_contact_history.kind` aceita também `desarquivado` (histórico antigo intacto). Nenhuma tabela nova.
- Regra: se já existir outra regra igual no lugar, avisa que não dá para desfazer.
- Testado no banco de verdade (transação desfeita): contato e rascunho arquivam e desarquivam, histórico registra, desarquivar duas vezes é recusado. A regra não foi testada no banco (só existe a global); foi testada no simulador.
