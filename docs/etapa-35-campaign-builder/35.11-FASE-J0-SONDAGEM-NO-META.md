## 3. Teste 2: dois vídeos por posicionamento + 3 textos e 3 títulos → **NÃO CONFIRMADO**

- A ferramenta do Meta usada no teste **recusa** várias opções de texto junto com vídeo por posicionamento: "With placement_customizations, use message, headline, and description".
- Essa é uma regra da ferramenta. **Não prova** que a API do Meta recuse: a API aceita listas de textos dentro do mesmo `asset_feed_spec`.
- **Como resolver:**
  - se o Ander já fez isso no Gerenciador (os 2 vídeos e os 3 textos no **mesmo** anúncio), basta indicar um desses anúncios. O CRM lê a estrutura, só leitura, e copia exatamente;
  - se não, o próprio CRM tenta na J.2 (só o criativo, nada no ar). Se o Meta recusar, usa o plano B: 2 vídeos com 1 texto, ou 1 anúncio por texto. O CRM mostra qual dos dois caminhos usou.
